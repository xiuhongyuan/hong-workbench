📲 个人工作台 · 多端同步图文指引

跟着图走，10 分钟内让手机和电脑数据互通，并把工作台装成 APP 点图标即用。

① GitHub Gist 推荐

免费、无需信用卡、最稳。需一个 GitHub 账号。

② jsonbin.io

更简单（邮箱注册拿 Key），但国内偶尔不稳。

🟢 方式一：GitHub Gist（推荐）

用 GitHub 的「代码片段(Gist)」当免费云盘，工作台自动读写它实现多端同步。

1

注册 / 登录 GitHub 账号

没有账号就先注册（免费，30 秒）。已有则直接登录。

  • 打开 github.com/signup 注册，或 github.com/login 登录
  • 记住用户名和密码（或用邮箱验证码登录）
2

打开「生成 Token」页面

Token 相当于工作台访问你 Gist 的「钥匙」，只能在这里生成一次，生成后记得复制保存。

  • 登录后访问：github.com/settings/tokens
  • 点右上角绿色按钮 「Generate new token」→「Generate new token (classic)」
github.com/settings/tokens
3

填写 Token 信息（关键：勾选 gist 权限）

按下图填写，重点是 ☑ gist 一定要勾上，否则工作台无法读写。

  • Note（备注）：填 workbench-sync
  • Expiration（有效期）：选 No expiration（永不过期，省得以后重来）
  • 下滑到 scopes，只勾 gist 这一项即可
  • 拉到底点绿色 「Generate token」
New personal access token
⚠️ 生成后页面只显示一次这串 ghp_... 字符，立刻复制保存到备忘录。关掉页面就再也看不到了。
4

填进工作台并测试

回到工作台「⚙️ 数据同步」页面，按图操作：

  • 同步后端：选 GitHub Gist
  • GitHub Token：粘贴刚才复制的 ghp_...
  • Gist ID：留空（首次保存自动创建）
  • 先点 🔌 测试连接 → 看到「✅ GitHub 连接成功」说明钥匙有效
  • 再点 💾 保存配置 → 自动创建 Gist 并首次同步
工作台 · 数据同步
5

手机 / 其他设备同步

在另一台设备打开同一个工作台链接，进入「⚙️ 数据同步」：

  • 同样选 GitHub Gist，粘贴同一个 Token
  • 这次把自动生成的 Gist ID 也填进去（在电脑端保存后，Gist ID 框里会出现一串字符，复制给它）
  • 点「🔄 立即同步」→ 两边数据应完全一致
  • 以后任意一端改了任务，约 1.5 秒后自动同步到另一端
💡 提示：Gist ID 在保存配置后会出现在「Gist ID」输入框里，复制下来备用即可。

🔵 方式二：jsonbin.io（更简单）

只要一个邮箱就能拿到 Key，适合不想注册 GitHub 的情况。

1

注册并拿到 API Key

  • 打开 jsonbin.io → 用邮箱注册 / 登录
  • 登录后在 Dashboard 找到你的 Secret API Key（形如 X-X-X-X-xxxx）
  • 复制这串 Key
jsonbin.io/dashboard
2

填进工作台

  • 同步后端：选 jsonbin.io
  • jsonbin API Key：粘贴 Key
  • Bin ID：留空（首次自动创建）
  • 先「🔌 测试连接」→ 再「💾 保存配置」
⚠️ 国内网络偶尔连不上 jsonbin，若测试失败可换回 GitHub Gist 方式。

📱 把工作台装成 APP（点图标即用）

装好后离线也能看历史内容，不用每次输网址。

1

电脑端（Edge / Chrome）

打开工作台链接 → 右上角 ⋮ 或 ⋯ → 找到「应用 / 安装」→「将此站点作为应用安装」→ 桌面出现图标。

2

安卓（Chrome）

点右上角 ⋮ →「添加到主屏幕」→ 命名「工作台」→ 主屏出现图标。

3

iPhone（Safari）

点底部「分享」按钮 → 上滑找到「添加到主屏幕」→ 主屏出现图标。

📌 只要用同一个工作台链接安装，APP 图标打开的就是这份工作台，配合上面的云端同步，多端数据一致。

🌐 永久在线的主屏图标（推荐，不休眠）

CloudStudio 沙箱会休眠，用它加主屏会失效。下面是已部署的永久在线链接（基于 GitHub Gist，永不休眠）。

1

用 iPhone 的 Safari 打开

复制下面链接，在 Safari（不是微信）里打开：

https://htmlpreview.github.io/?https%3A%2F%2Fgist.githubusercontent.com%2FXiuhongyuan%2F5b67c9bd69aac8fe7f12d457bdd2bdf4%2Fraw%2Findex.html

2

添加到主屏幕

点底部「分享」→「添加到主屏幕」→ 命名「红红工作台」→ 主屏出现图标。

⚠️ 该链接走第三方 htmlpreview 代理，图标为代理默认样式。想要自定义图标 + 最稳，需把工作台部署到 GitHub Pages（要求 Token 有 repo 权限），详见下方「升级到 GitHub Pages」。
3

升级到 GitHub Pages（自定义图标、永不休眠）

  • 去 GitHub → Settings → Developer settings → Personal access tokens
  • 删除旧 Token，重新生成一个，权限勾 repo（全选 repo 类），过期选"永不过期"
  • 把新 ghp_xxx 发给助手 → 自动建仓库、开 Pages
  • 得到 https://xiuhongyuan.github.io/仓库名/ 永久链接 → Safari 加主屏即自定义图标 APP

📲 手机怎么打开「红红的个人工作台.html」

单文件版发到手机后，按机型用下面正确方式打开（之前的图文里 iPhone 走法有误，这里更正）。

第一步：把文件传到手机

  • 微信：电脑微信 → 文件传输助手 → 把 红红的个人工作台.html 拖进去发给自己 → 手机微信收到
  • QQ / 网盘：同理发"我的手机"或存百度网盘 / 微云
  • 数据线：连电脑 → 拷到手机"内部存储"任意文件夹

第二步：在手机上打开

A

🤖 安卓（最省事）

微信里点开文件 → 右上角 ⋮ → 用其他应用打开 → 选 Chrome / 系统浏览器；或直接在"文件管理"App 里找到该文件点开。

B

🍎 iPhone —— 直接点开（推荐，无需联网）

微信里长按文件 → 存储到"文件" → 打开 iPhone 自带 "文件" App → 找到 红红的个人工作台.html → 直接点它，iOS 会直接渲染打开，功能完整、离线可用。

⚠️ 别用"共享 → Safari"这一路：iPhone 不会把本地 HTML 列为 Safari 可打开目标，所以没有 Safari 选项。直接用"文件"App 点开即可。
C

🍎 iPhone —— 共享到"图书"

"文件"App 里长按该 HTML → 共享 → 在列表里找 "图书"（Books，不是 Safari）→ 点开后图书会正常显示网页内容。

D

🍎 iPhone —— 想要主屏图标（必须走网址）

iOS 规定只有"在 Safari 打开一个网址"才能添加到主屏幕，本地文件做不到。所以想要主屏 APP 图标，请用云端链接：

  • 在 Safari（不是微信）里打开工作台云端链接
  • 底部 分享 按钮 → 上滑找到 "添加到主屏幕" → 主屏出现图标
  • 云端链接会休眠，但加到主屏的图标指向它，链接有效时即可用
🔁 一个数据提醒：单文件版的数据只存在"当前这台手机的这个浏览器"里。换浏览器、清缓存、换设备都会丢；要互通请到工作台左侧「⚙️ 数据同步」填 GitHub Token，或用"导出 / 导入备份"手动传。

🛟 不联网也能用：手动备份（兜底）

不想用任何云服务？用这个方式同样能手机电脑互通，数据完全在自己手里。

  • 电脑上「⚙️ 数据同步」→ 点 📤 导出备份，得到一个 JSON 文件
  • 把文件发到微信文件传输助手 / 百度网盘
  • 手机打开工作台 →「📥 导入备份」→ 选这个文件 → 数据立刻一致
